What Is CSS?

CSS stands for Cascading Style Sheets. It controls how HTML content looks on a webpage.

CSS can change colours, text size, spacing, backgrounds and page layout.

CSS Syntax

A CSS rule contains a selector and a group of declarations. Each declaration has a property and a value. 

p {
    color: blue;
    font-size: 18px;
}

In this example, p selects paragraphs. The color property changes the text colour, and font-size changes the text size.

Three Ways to Use CSS

1. Inline CSS

Inline CSS is written inside an HTML element using the style attribute. 

<p style="color: blue;">
    Hello world
</p>

2. Internal CSS

Internal CSS is written inside a style element in the HTML head. 

<style>
    p {
        color: blue;
    }
</style>

3. External CSS

External CSS is written in a separate .css file. An HTML page connects to it using a link element. 

<link rel="stylesheet" href="../css/styles.css">

This website uses external CSS so that all pages can share the same styles.

The CSS Box Model

Every HTML element can be treated as a box. The CSS box model has four main parts.

  • Content: The text or image inside the box.
  • Padding: Space around the content.
  • Border: The line around the padding and content.
  • Margin: Space outside the border.
.example-box {
    padding: 10px;
    border: 2px solid black;
    margin: 15px;
}

Padding adds space inside the border. Margin adds space outside the border.

Responsive Design

Responsive design helps a website work on different screen sizes, including phones, tablets and desktop computers.

Flexible layouts and media queries help the content fit different screens. 

@media (max-width: 600px) {
    body {
        font-size: 16px;
    }
}

This media query applies the rule when the viewport width is 600 pixels or less.

What I Learned
