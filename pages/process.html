How I planned and developed my learning website

1. Project Overview

I created this website as part of Practical Work I. The main purpose is to practise HTML and CSS and explain basic web development concepts to beginners.

While working on this project, I learned how to organise content, connect pages and create a website that is easy to use.

2. Planning and Structure

I organised the project into separate folders to make the files easier to find and manage.

  • index.html: The home page.
  • pages/: The HTML Basics, CSS Basics and Process pages.
  • css/styles.css: The shared stylesheet.
  • images/: The folder for website images.
  • documents/: The folder for project documents.
  • README.md: Project information and instructions.

I used relative links to connect the pages and the shared stylesheet.

3. HTML Development

I used semantic HTML elements to organise the content of each page.

  • header: Contains the page title and introduction.
  • nav: Contains links to the website pages.
  • main: Contains the main page content.
  • section: Groups related information.
  • footer: Contains author and contact information.

This structure makes the HTML easier to read and helps users understand the content.

4. CSS and Responsive Design

I used an external stylesheet called styles.css to keep the website design consistent across the different pages.

CSS controls colours, spacing, text size and page layout. Flexbox or Grid can arrange content, while media queries can adapt the layout to smaller screens.

I checked the layout at mobile, tablet and desktop screen sizes and adjusted the CSS where needed.

5. Testing and Validation

I used the W3C HTML Validator to check the HTML pages and the W3C CSS Validator to check the stylesheet.

I tested the navigation links, email link and downloadable files in the browser. I also checked the website at approximately 360, 768 and 1280 pixels wide and corrected the issues I found.

The screenshots and testing results in my project report provide supporting evidence of the work.

6. Problems and Solutions

Problem: Finding the correct file

During development, I had difficulty opening index.html in the VS Code editor. I learned to open the file from the Explorer and use the editor area to write the code.

Problem: Using relative paths

HTML files inside the pages folder need different paths to reach files in the main project folder. I used ../ to move up one folder level when linking to index.html or css/styles.css.

I checked the links in the browser to make sure they worked correctly.

7. What I Learned

This project helped me practise HTML structure, CSS styling and website navigation. I also learned the importance of accessibility, responsive design and testing.

In the future, I would like to improve the website design and learn more about web development.
