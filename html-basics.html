What Is HTML?

HTML stands for HyperText Markup Language. It is used to organise content on a webpage.

For example, HTML can create headings, paragraphs, lists, links and images.

Basic HTML Structure

Every HTML page needs a basic document structure. The following example shows its main parts. 

<!DOCTYPE html>
<html lang="en">
<head>
    <title>My First Page</title>
</head>
<body>
    <h1>Hello World</h1>
    <p>This is my first webpage.</p>
</body>
</html>

The head contains page information. The body contains the content shown in the browser.

Common HTML Elements

  • h1 creates the main heading.
  • p creates a paragraph.
  • a creates a link.
  • ul creates a bullet list.
  • li creates a list item.

Common HTML Elements Table

This table explains some common HTML elements and their uses.

Common HTML Elements and Their Uses
HTML Element Purpose Example
<h1> Creates a main heading. Page title
<p> Creates a paragraph. Text content
<a> Creates a link. Another page
<ul> Creates a bullet list. List of topics
<img> Displays an image. Picture or diagram

Why Semantic HTML Matters

Semantic elements describe the purpose of content. For example, header, nav, main and footer help organise a webpage clearly.

Clear structure can also help people using assistive technologies understand a page.
